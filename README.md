# Speedtest RT.RU Integration for Home Assistant

This integration automatically downloads and runs the `speedtest` binary from [https://speedtest.rt.ru](https://speedtest.rt.ru) to provide Download, Upload, and Ping sensors in Home Assistant.

### Installation
1. Copy `custom_components/speedtest_rt_ru` to your Home Assistant `config/custom_components` directory.
2. Restart Home Assistant.
3. Add the integration via the UI (search for **Speedtest RT.RU**).

The binary is downloaded automatically on first setup.
